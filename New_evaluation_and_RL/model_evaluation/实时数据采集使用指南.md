# 实时数据采集使用指南

## 📌 快速开始

### 1. 在配置文件中启用实时采集

在 `configs/models_config.yaml` 的 `evaluation` 部分添加：

```yaml
evaluation:
  # ... 其他配置 ...

  # 启用实时数据采集
  enable_realtime_collection: true  # ← 设为 true 启用

  # 数据存储目录
  collection_output_dir: "./evaluation_data"

  # 检查点间隔（每N条记录保存一次）
  checkpoint_interval: 10

  # 断点续测时跳过已处理样本
  skip_processed: true
```

### 2. 运行评测

```bash
# 使用默认配置
python scripts/run_unified_evaluation.py --config configs/models_config.yaml

# 使用实时采集示例配置
python scripts/run_unified_evaluation.py --config configs/models_config_realtime.yaml
```

## 🔄 断点续测功能

### 自动恢复机制

1. **评测中断时**：系统自动保存进度到 `resume_info.json`
2. **下次启动时**：自动检测未完成的评测并从断点恢复
3. **跳过已处理**：避免重复评测相同样本

### 手动控制恢复

```bash
# 查看恢复信息
cat evaluation_data/resume_info.json

# 删除恢复信息，从头开始
rm evaluation_data/resume_info.json
```

## 📊 数据文件说明

生成的文件结构：

```
evaluation_data/
├── evaluation_data_20250914_120000.jsonl   # 实时评测记录
├── checkpoint_20250914_120000.json         # 进度检查点
├── resume_info.json                        # 恢复信息
└── realtime_summary_20250914_123000.json   # 汇总统计
```

### JSONL 记录格式

每行一个 JSON 对象，包含：

```json
{
  "sample_id": "md5_hash",           // 样本唯一标识
  "timestamp": "2025-09-14T12:00:00", // 评测时间
  "model_name": "qwen-turbo",        // 模型名称
  "benchmark": "gsm8k",              // 数据集
  "input": {                         // 输入信息
    "prompt": "...",
    "extra_info": {}
  },
  "output": {                        // 输出信息
    "solution": "...",
    "truncated": false
  },
  "evaluation": {                    // 评测结果
    "success": true,
    "score": 0.85,
    "error": null,
    "timeout": false,
    "execution_time": 2.5
  },
  "performance": {                   // 性能指标
    "latency": 1.2,
    "total_time": 3.7
  }
}
```

## 🔍 数据分析

### 读取 JSONL 数据

```python
import json

# 读取所有记录
records = []
with open('evaluation_data/evaluation_data_20250914_120000.jsonl', 'r') as f:
    for line in f:
        records.append(json.loads(line))

# 分析成功率
total = len(records)
successful = sum(1 for r in records if r['evaluation']['success'])
print(f"成功率: {successful/total*100:.1f}%")

# 按模型统计
from collections import defaultdict
model_scores = defaultdict(list)
for r in records:
    if r['evaluation']['success']:
        model_scores[r['model_name']].append(r['evaluation']['score'])

for model, scores in model_scores.items():
    avg_score = sum(scores) / len(scores)
    print(f"{model}: 平均分 {avg_score:.3f}")
```

### 使用 Pandas 分析

```python
import pandas as pd
import json

# 加载数据到 DataFrame
records = []
with open('evaluation_data/evaluation_data_20250914_120000.jsonl', 'r') as f:
    for line in f:
        record = json.loads(line)
        # 展平嵌套结构
        flat_record = {
            'sample_id': record['sample_id'],
            'model_name': record['model_name'],
            'benchmark': record['benchmark'],
            'success': record['evaluation']['success'],
            'score': record['evaluation']['score'],
            'timeout': record['evaluation']['timeout'],
            'latency': record['performance']['latency']
        }
        records.append(flat_record)

df = pd.DataFrame(records)

# 基础统计
print(df.groupby('model_name')['score'].describe())

# 成功率对比
success_rate = df.groupby('model_name')['success'].mean() * 100
print(f"成功率:\n{success_rate}")

# 按 benchmark 分组
benchmark_stats = df.groupby(['benchmark', 'model_name'])['score'].agg(['mean', 'std', 'count'])
print(f"Benchmark 统计:\n{benchmark_stats}")
```

## ⚙️ 配置参数详解

| 参数 | 类型 | 默认值 | 说明 |
|-----|------|--------|------|
| `enable_realtime_collection` | bool | false | 是否启用实时采集 |
| `collection_output_dir` | str | "./evaluation_data" | 数据文件存储目录 |
| `checkpoint_interval` | int | 10 | 每N条记录保存检查点 |
| `skip_processed` | bool | true | 恢复时是否跳过已处理样本 |

## 🎯 使用场景

### 场景 1：长时间评测

适合评测大量样本或多个模型时使用：

```yaml
evaluation:
  enable_realtime_collection: true
  checkpoint_interval: 50  # 每50条保存一次
```

### 场景 2：调试模式

频繁保存，便于调试：

```yaml
evaluation:
  enable_realtime_collection: true
  checkpoint_interval: 1  # 每条都保存
  batch_size: 1  # 单条处理
```

### 场景 3：生产环境

平衡性能和可靠性：

```yaml
evaluation:
  enable_realtime_collection: true
  checkpoint_interval: 100  # 减少IO开销
  batch_size: 8  # 并行处理
```

## 🔧 故障排查

### 问题：发现重复记录

**原因**：`resume_info.json` 状态异常

**解决**：
```bash
rm evaluation_data/resume_info.json
rm evaluation_data/checkpoint_*.json
# 重新开始评测
```

### 问题：恢复后进度不对

**原因**：检查点文件损坏

**解决**：
1. 检查 `checkpoint_*.json` 是否完整
2. 查看 `evaluation_data_*.jsonl` 实际记录数
3. 手动修改 `resume_info.json` 中的 `record_count`

### 问题：内存占用过高

**原因**：处理的样本ID集合过大

**解决**：
```yaml
evaluation:
  checkpoint_interval: 10  # 更频繁地清理内存
  batch_size: 2  # 减少并发数
```

## 📈 性能影响

实时采集的开销很小：
- **写入延迟**：~5ms/记录
- **内存占用**：~100KB + 样本ID集合
- **磁盘空间**：~5-10KB/记录

建议：
- SSD 硬盘可设置 `checkpoint_interval: 1`
- HDD 硬盘建议 `checkpoint_interval: 10-50`
- 网络存储建议 `checkpoint_interval: 100+`

## 📝 注意事项

1. **数据隐私**：采集的数据包含完整的输入输出，注意保护敏感信息
2. **磁盘空间**：长时间运行需要足够的磁盘空间
3. **并发安全**：使用异步锁保证文件写入的原子性
4. **时区问题**：时间戳使用 ISO 格式，包含时区信息
