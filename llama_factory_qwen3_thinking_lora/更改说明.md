# 训练过程样本生成功能 - 更改说明

## 功能概述

本功能为LLaMA-Factory添加了训练过程中定期生成样本的能力，可以实时监控模型训练效果。该功能会在指定步数间隔时，从训练集中随机选择样本让模型生成输出，并在控制台显示或保存到文件。

## 文件更改详情

### 1. 修改的文件

#### 1.1 `src/llamafactory/hparams/finetuning_args.py`
**修改位置：** 第516-535行

**添加的参数：**
- `sample_generation_steps`: 训练过程中生成样本的步数间隔（设为None禁用）
- `sample_generation_num`: 每次生成的样本数量（默认1个）
- `sample_generation_max_tokens`: 每个样本生成的最大token数（默认128）
- `sample_generation_temperature`: 生成时的温度参数（默认0.7）
- `save_generation_samples`: 是否保存生成的样本到文件（默认False）

#### 1.2 `src/llamafactory/train/callbacks.py`
**修改位置：**
- 第17-22行：新增导入（`random`, `datetime`）
- 第389-531行：新增`SampleGenerationCallback`类

**主要功能：**
- 实现了完整的样本生成回调类（143行代码）
- 在训练过程中按指定间隔生成样本
- 过滤生成参数，只传递有效参数给model.generate()
- 支持将生成历史保存为JSONL文件

#### 1.3 `src/llamafactory/train/sft/workflow.py`
**修改位置：**
- 第26行：添加`SampleGenerationCallback`导入
- 第82-95行：添加回调初始化逻辑

**功能：** 当设置了`sample_generation_steps`参数时，自动创建并添加样本生成回调

### 2. 新增的文件

#### 2.1 `examples/train_lora/llama3_lora_sft_with_generation.yaml`
**用途：** 示例配置文件，展示如何使用样本生成功能 不是真的训练脚本!!!

**内容：** 包含启用样本生成参数的完整训练配置

## 使用方法

### 1. 基本使用

在训练配置文件（YAML）中添加以下参数：

```yaml
# 样本生成配置
sample_generation_steps: 100        # 每100步生成一次样本
sample_generation_num: 2            # 每次生成2个样本
sample_generation_max_tokens: 128   # 最多生成128个token
sample_generation_temperature: 0.7  # 生成温度
save_generation_samples: true       # 保存生成历史到文件
```

### 2. 命令行使用

```bash
# 使用示例配置文件训练
llamafactory-cli train examples/train_lora/llama3_lora_sft_with_generation.yaml

# 或在命令行直接指定参数
llamafactory-cli train \
    --model_name_or_path meta-llama/Meta-Llama-3-8B-Instruct \
    --stage sft \
    --sample_generation_steps 100 \
    --sample_generation_num 2 \
    --sample_generation_max_tokens 128 \
    ...其他训练参数
```

### 3. 输出示例

训练过程中会看到类似输出：

```
========== Sample Generation at Step 100 ==========
Sample 1:
Input: 请解释什么是机器学习？
Generated: 机器学习是人工智能的一个分支，它使计算机能够从数据中学习...

Sample 2:
Input: Python中如何定义函数？
Generated: 在Python中，使用def关键字来定义函数...
==================================================
```

如果启用了`save_generation_samples`，生成历史会保存到：
`output_dir/generation_samples.jsonl`

## 注意事项

1. **向后兼容性**：所有更改都是向后兼容的，现有配置无需修改即可正常运行
2. **性能影响**：生成样本会占用少量训练时间，建议`sample_generation_steps`设置为100-500之间
3. **内存使用**：生成过程会使用额外内存，特别是设置较大的`sample_generation_max_tokens`时
4. **依赖项**：无需安装额外依赖，功能使用项目已有的库

## 高级配置

### 自定义生成参数

可以通过修改`callbacks.py`中的生成参数来调整生成行为：

```python
# 在SampleGenerationCallback类中
generating_args = {
    "max_new_tokens": self.max_tokens,
    "temperature": self.temperature,
    "do_sample": True,           # 可改为False使用贪婪解码
    "top_p": 0.9,                # 可添加nucleus sampling
    "repetition_penalty": 1.1,   # 可添加重复惩罚
}
```

### 自定义输出格式

修改`_generate_and_print_samples`方法可以自定义输出格式或添加更多信息（如生成时间、置信度等）。

## 问题排查

1. **如果生成功能不工作**：
   - 确认`sample_generation_steps`参数已设置
   - 检查训练步数是否达到生成间隔
   - 查看日志是否有错误信息

2. **如果生成质量差**：
   - 可能是训练初期模型还未收敛
   - 尝试调整`temperature`参数（更低=更保守，更高=更随机）
   - 增加训练步数后再观察

3. **如果保存的文件找不到**：
   - 检查`output_dir`参数设置
   - 确认`save_generation_samples`设为`true`
   - 文件保存在`{output_dir}/generation_samples.jsonl`
