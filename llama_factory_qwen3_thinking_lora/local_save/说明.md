# 生成样本处理工具说明

## 📚 工具概述

本目录包含两个用于处理 LLaMA-Factory 训练过程生成样本的工具：

1. **`extract_outputs.py`** - 提取生成样本的核心输出内容
2. **`jsonl_to_python_files.py`** - 将生成样本转换为独立的 Python 文件

## 🔧 工具1: extract_outputs.py

### 功能
从 JSONL 生成样本文件中提取 `output` 内容，保留关键元数据（step、sample_idx、timestamp）。

### 使用方法

#### 快速使用（自动检测文件）
```bash
python extract_outputs.py
```

#### 指定文件处理
```bash
python extract_outputs.py rank=8_generation_samples_20250903_062429.jsonl
```

#### 自定义输出文件
```bash
python extract_outputs.py input.jsonl -o output.jsonl
```

#### 只分析文件结构
```bash
python extract_outputs.py input.jsonl -a
```

### 输出格式
```json
{"step": 5, "sample_idx": 0, "output": "生成的内容...", "timestamp": "2025-09-03T06:27:54"}
```

## 🐍 工具2: jsonl_to_python_files.py

### 功能
将 JSONL 生成样本转换为独立的 Python 文件，分离思考过程和代码部分。

### 使用方法

#### 基本使用
```bash
python jsonl_to_python_files.py input.jsonl output_dir/
```

#### 实际例子
```bash
# 将样本转换到 rank_8 目录
python jsonl_to_python_files.py rank=8_generation_samples_20250903_062429.jsonl rank_8/
```

#### 预览文件结构（不转换）
```bash
python jsonl_to_python_files.py input.jsonl output_dir/ -p
```

#### 使用测试脚本（推荐新手）
```bash
bash test_conversion.sh
```

### 输出格式
生成的每个 `.py` 文件包含：

```python
#!/usr/bin/env python
"""
Generated from training step 5, sample 0
Timestamp: 2025-09-03T06:27:54.868369
"""

"""
THINKING PROCESS:
[<think></think> 部分的思考内容]
"""

[```python 代码块的实际代码]
```

### 文件命名规则
- 格式：`step_{训练步数}_{样本索引}.py`
- 例子：`step_5_0.py`, `step_10_1.py`

## 🎯 典型使用场景

### 场景1：快速查看生成质量演变
```bash
# 提取所有输出，便于对比分析
python extract_outputs.py generation_samples.jsonl -o clean_outputs.jsonl
```

### 场景2：创建可执行的代码库
```bash
# 将生成样本转换为Python文件，便于测试和分析
python jsonl_to_python_files.py generation_samples.jsonl code_samples/
```

### 场景3：批量处理多个实验结果
```bash
# 处理不同rank的实验结果
python jsonl_to_python_files.py rank8_samples.jsonl rank_8/
python jsonl_to_python_files.py rank16_samples.jsonl rank_16/
python jsonl_to_python_files.py rank32_samples.jsonl rank_32/
```

## 📊 处理流程示例

```bash
# 1. 首先分析文件结构
python extract_outputs.py your_file.jsonl -a

# 2. 提取核心输出（可选）
python extract_outputs.py your_file.jsonl

# 3. 转换为Python文件
python jsonl_to_python_files.py your_file.jsonl output_folder/

# 4. 查看结果
ls output_folder/
head output_folder/step_*.py
```

## ⚠️ 注意事项

1. **文件格式**：输入必须是有效的 JSONL 格式
2. **权限**：确保脚本有可执行权限（`chmod +x *.py`）
3. **目录**：输出目录会自动创建，不需要预先存在
4. **覆盖**：如果输出文件已存在，会被覆盖

## 🔍 故障排查

### 常见问题

**Q: 脚本报告 JSON 解析错误**
```bash
# 使用分析功能检查文件格式
python extract_outputs.py your_file.jsonl -a
```

**Q: 生成的 Python 文件为空或格式不对**
```bash
# 预览数据结构，确认包含所需字段
python jsonl_to_python_files.py your_file.jsonl output/ -p
```

**Q: 没有找到 <think> 或代码块**
- 这是正常现象，脚本会保留原始输出作为注释
- 检查生成样本是否确实包含思考过程和代码

### 输出统计

两个工具都会显示处理统计：
- ✅ 成功处理的记录数
- ❌ 错误记录数（如有）
- 📁 输出文件位置
